# Archive

This directory is retained research history, not a deletion queue.

- `bundles/` contains the superseded `FINAL` bundle and intermediary package
  attempts.
- `setup/` contains superseded setup code whose distinct bytes are preserved,
  including the original pre-path-fix E11 finalizer.

Byte-identical installer copies formerly kept in `duplicates/` were removed
after SHA256 verification; the historical canonical bytes remain in
`setup/install_e11_challengers_original.py`.
