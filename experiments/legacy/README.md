# Legacy experiment series

The `v_series/` and `h_series/` directories preserve the original identifiers,
agents, comparisons, diagnostics, traces, and recorded analysis outputs. No
number was reused, renumbered, or merged.

Compatibility symlinks expose the unchanged `public_agents/` dependency and the
v11/v15 modules expected by historical scripts. New work must use a new E-series
experiment number instead of changing these files into a different strategy.
